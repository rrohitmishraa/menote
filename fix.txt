PHASE 12 — CLICKABLE URLS

MeNote is stable and feature-complete.

Implement ONLY clickable URL behavior.

Do NOT modify:

- NSTextView architecture
- persistence architecture
- scrolling
- wrapping
- line numbers
- Find
- Bold/Italic
- text colors
- slash commands
- word counter
- TXT import/export
- About/Help
- Launch at Login
- menu-bar lifecycle
- toolbar layout

==================================================
1. URL DETECTION
==================================================

Automatically detect URLs in the editor.

Support:

https://example.com
http://example.com

Also support common URLs with:

- paths
- query parameters
- fragments
- ports
- subdomains

Example:

https://example.com/test?q=hello

Do not require the user to manually format the URL.

==================================================
2. LINK APPEARANCE
==================================================

Detected URLs should use a subtle native link appearance.

Use the system's appropriate link color.

Do not introduce a custom bright color.

Do not make the URL excessively bold.

The link should remain readable in:

- Light Mode
- Dark Mode

==================================================
3. CLICKING
==================================================

Clicking a detected URL should open it using the user's default browser.

Use the native macOS URL-opening mechanism.

Do NOT embed a browser inside MeNote.

Do NOT create a web view.

==================================================
4. EDITING
==================================================

URLs must remain normal editable text.

The user must be able to:

- place the cursor inside a URL
- edit it
- delete it
- select it
- copy it
- paste it

If the URL becomes invalid after editing, it should no longer behave as a clickable link.

If a valid URL is created through editing, it should become clickable.

==================================================
5. SELECTION

Clicking/selecting a URL must not break normal text selection.

The user should still be able to select the URL and copy it.

⌘C should copy the actual URL text.

Do not copy hidden metadata.

==================================================
6. COMMAND CLICK

If appropriate for native macOS text behavior, support:

⌘ + click

to open the URL.

Do not interfere with normal clicking behavior.

If ordinary clicking already works correctly with NSTextView conventions, preserve the simplest reliable implementation.

==================================================
7. PERSISTENCE

Links must survive saving and reopening.

Test:

1. Type URL.
2. Quit MeNote.
3. Relaunch.
4. Verify URL remains clickable.

Do not create a separate link database.

Store the link as part of the existing attributed text/persistence mechanism.

==================================================
8. FORMATTING COMPATIBILITY

Links must work with:

- Bold
- Italic
- text colors

Applying Bold, Italic, or a text color must not accidentally destroy the URL's clickability.

Similarly, detecting a URL must not remove existing formatting unnecessarily.

==================================================
9. FIND

Find must continue working with URLs.

For example:

⌘F

Search:

example.com

should find the URL normally.

Do not modify the existing Find architecture.

==================================================
10. WRAPPING / SCROLLING

Long URLs should behave sensibly inside the editor.

Do not introduce horizontal scrolling.

Preserve the existing text-wrapping behavior.

Vertical scrolling must continue working normally.

==================================================
11. TXT EXPORT

Exporting a note to TXT must produce the actual URL text.

Example:

https://example.com

Do NOT export:

HTML
Markdown
hidden link metadata
custom markup

The TXT file should contain:

https://example.com

==================================================
12. TXT IMPORT

When importing a TXT file containing URLs:

https://example.com

the URL should be detected and become clickable.

Do not require the user to manually format imported URLs.

==================================================
13. SLASH COMMAND COMPATIBILITY

Do not interfere with:

/line
/list
/number

URLs such as:

https://example.com/path

must NOT accidentally trigger slash commands.

==================================================
14. URL BOUNDARIES

Do not accidentally include common trailing punctuation in the URL.

Example:

Visit https://example.com.

The clickable URL should be:

https://example.com

The final period should remain normal text.

Handle common punctuation correctly.

==================================================
15. PERFORMANCE

Do not continuously perform expensive full-document processing on every keystroke if avoidable.

Keep URL detection lightweight.

Do not introduce noticeable typing latency.

==================================================
16. IMPORTANT IMPLEMENTATION RULE

Use NSTextView's existing attributed-string/link capabilities where appropriate.

Do NOT create custom link views.

Do NOT create a separate browser component.

Do NOT create a custom URL database.

Keep links as attributed text.

==================================================
17. TESTING

Test:

1. Type https://example.com
2. Click it.
3. Verify default browser opens.
4. Edit the URL.
5. Delete the URL.
6. Paste a URL.
7. Import a TXT containing a URL.
8. Quit and reopen.
9. Click the restored URL.
10. Apply Bold.
11. Apply Italic.
12. Apply a text color.
13. Find the URL.
14. Copy the URL.
15. Export to TXT.
16. Verify exported text contains the exact URL.
17. Test Light Mode.
18. Test Dark Mode.
19. Test long URLs.
20. Test URL followed by punctuation.

==================================================
18. REGRESSION PROTECTION

Everything below must continue working:

- typing
- Enter
- scrolling
- wrapping
- line numbers
- Bold
- Italic
- text colors
- undo
- redo
- Find
- slash commands
- /line
- /list
- /number
- word counter
- TXT import
- TXT export
- persistence
- About
- Launch at Login
- keyboard shortcuts
- ⌘Q

Do not modify unrelated systems.
