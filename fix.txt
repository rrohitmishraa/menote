PHASE 3B — FIX UNDO FOR BOLD / ITALIC ONLY

Bold and italic formatting work correctly, but ⌘Z does not undo formatting changes.

Normal editing undo already works correctly.

DO NOT change the existing editor architecture or formatting behavior.

==================================================
CURRENT BEHAVIOR
==================================================

Works:

- Typing → undo works
- Deleting → undo works
- Enter → undo works
- Bold → applies correctly
- Italic → applies correctly

Broken:

- Apply Bold → ⌘Z does NOT remove the bold formatting
- Apply Italic → ⌘Z does NOT remove the italic formatting

==================================================
ROOT CAUSE TO INVESTIGATE
==================================================

The formatting implementation is likely modifying NSTextStorage attributes directly.

For example:

textStorage.addAttribute(...)
textStorage.removeAttribute(...)
textStorage.setAttributes(...)

These operations may not automatically create an undo operation in the NSTextView's undo manager.

Do NOT simply rebuild the editor or replace the NSTextView.

==================================================
REQUIRED FIX
==================================================

Make Bold and Italic formatting operations participate in the SAME NSUndoManager used by NSTextView.

When applying a formatting change:

1. Capture the previous attributed-string attributes for the affected range.
2. Apply the new attributes.
3. Register an undo operation that restores the previous attributes.
4. The undo operation must itself correctly register the inverse operation so ⇧⌘Z works.

The formatting operation should behave like a normal NSTextView editing operation.

==================================================
IMPORTANT
==================================================

Do NOT manually manipulate the visible text.

Do NOT store formatting commands inside the text.

Do NOT create a second undo manager.

Use the NSTextView's existing undoManager.

Do NOT break:

- ⌘Z
- ⇧⌘Z
- typing
- selection
- copy/paste
- persistence
- line numbers
- scrolling
- wrapping
